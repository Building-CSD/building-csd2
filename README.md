# Center for Spirituality and Dialogue website

A static website for the Center for Spirituality and Dialogue (CSD), 2601 Durant Avenue, Berkeley.

## Pages

| Page | File |
|---|---|
| Home | `index.html` |
| Our Space | `our-space.html` |
| Events | `events.html` |
| Student Groups | `student-groups.html` |
| Host with us | `host-with-us.html` |
| Our Team | `our-team.html` |
| Support us | `support-us.html` |

Images, the hero video and partner logos live in `assets/`.

## Viewing it on the web

The site is plain HTML with no build step. Turn on GitHub Pages under **Settings → Pages**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`. It will then be served at `https://building-csd.github.io/building-csd2/`.
